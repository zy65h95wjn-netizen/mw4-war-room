# MW4 War Room

Personal, installable iPhone companion for Modern Warfare 4.

## Features
- Player rank / Prestige, 33 launch weapons and weapon levels
- Saved loadouts and iron-sight defaults
- Clearly dated meta snapshots from different publishers (not live feeds)
- Calling card tracker, custom event checklist and Battle Pass section
- Manual career statistics and offline-capable access
- JSON progress export and import

## Install on iPhone
1. In GitHub, open **Settings → Pages**.
2. Under **Build and deployment**, choose **Deploy from a branch**, then select **main** and **/(root)**, then **Save**.
3. Open the published site in **Safari**, select **Share → Add to Home Screen → Add**.

## Privacy and source notes
This personal project is not affiliated with Activision. The website and its code are public; personal progression entered in the app stays in that browser's local storage and is not sent to GitHub. Export a backup regularly. The initial game and publisher rankings are dated 2026-10-27 and are not automatically refreshed; in-game unlock screens take priority. Use the source links in the app for current information.
